# How to Create Admin User - UPDATED ✅

## ✨ NEW: Register Directly as Admin (EASIEST WAY)

### Step 1: Go to Registration Page
Open your browser and go to:
```
http://localhost:3001/register
```

### Step 2: Select Admin Role
You'll now see **3 role options**:
- 👤 Customer
- 👷 Worker  
- 👨‍💼 **Admin** ← Click this one!

The Admin card has a purple gradient background.

### Step 3: Fill the Form

### Step 4: Register
Click the "Register" button.

### Step 5: Login as Admin
1. Go to `http://localhost:3001/login`
2. Email: **admin@test.com**
3. Password: **admin123**
4. Click Login

### Step 6: Access Admin Panel
After login, you'll see **"Admin Panel"** button in the navbar!

Click it to access:
